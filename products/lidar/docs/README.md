## Evidence discipline

Technical claims must continue to distinguish:

    FACT
    INFERENCE
    HYPOTHESIS
    DECISION
    OPEN QUESTION
    LIMITATION
    RESULT

A plausible interpretation must not become a documented fact without new
evidence.
